Philippine Data Summary Program

This notebook demonstrates the project's reusable Python modules for loading, filtering, transforming, and summarizing the Philippine Customs 2015 dataset.

Filtering rules:

  • Quarter (tq) = 2015q4
  • Dutiable value (dutiablevaluephp) >= PHP 1,000,000

The raw 2015.csv file should be placed in the project root folder.
